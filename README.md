# KI_Exam02_KSJ_TestGame
언리얼 블루프린트를 활용한 TPS게임 개인 프로젝트


언리얼 블루프린트 개인프로젝트
김수진
 
장르 : FPS / 1인칭 액션 슈팅 (첫 전투 튜토리얼 + 점령전)
주제
-      오버워치를 오마주한 1인 슈팅 액션 게임 (1vs다수 AI적)
개요
-      블리자드의 오버워치의 FPS 전투 시스템을 참고한 카피 프로젝트
-      한 명의 플레이어가 다수의 AI적과 맞서 싸우고 거점을 점령하는 구조
-      모든 유닛(플레이어 + AI)는 사망 시 일정 시간 후 리스폰(부활) 되어 전장을 지속적으로 유지한다.
-       
-      1. 플레이어(솔저76 타입 강화병사)
n  기본
u  체력 : 200HP
u  무기 : 돌격소총 사용( 20 데미지 )
u  재장전 : 1.5초
u  리스폰 : 사망 후 5초 후 시작 위치에서 자동 부활
 
n  스킬
u  무기 공격력 증가 : 기본 공격데미지 X 1.5배 -> 쿨타임 8초
u  이동속도 버프 증가 : 기본 속도 X 1.5배 -> 제한 없음
u  회복 기둥 생성 : 초당 40HP X 5초 -> 쿨타임 15초
u  궁극기 : 자동 조준 + 공격력 X 1.3배
 
-      2. AI 적
n  기본
u  타입 : 근거리 돌진형 / 원거리 사격형
u  체력 : 200HP
u  공격력 10 데미지
u  리스폰 : 사망 후 5초 후 랜덤 포인트에서 자동 부활
n  스킬
u  처치할수록 새로 스폰되는 적의 크기 + 10%, 공격력 + 10%
 
-      3. 맵
n  큐브맵(튜토리얼 / 연습장)
: 지속 리스폰 전투
: 적이 죽으면 부활하고, 일정 주기마다 새 적이 추가 스폰되는 방식
u  목표 : 시간 60초내에 AI적보다 많은 처치 달성
u  스타일 : 박스형 훈련장 아레나
u  초기 AI적 수 : 3~5명 (랜덤 스폰)
u  AI적 리스폰 : 5초마다 1~2명 새로 생성(사망 후 5초 뒤 리스폰)
u  결과 : 플레이어 vs AI 킬 카운트 비교 승패 판정
 
n  메인맵(점령전)
: 점점 강해지는 적 + 거점 점령 목표
u  목표 : 제한시간 3분 내에 15초 지속 기지점령 시 승리
u  스타일 : 오버워치 “리장타워” 참고 – 중앙 원형 거점 + 외관 순환 경로 구조
u  초기 AI적 수 : 3명
u  AI적 리스폰 : 10초마다 1명 새로 생성(사망 후 5초 뒤, 강화된 상태로 라스폰)
u  점령 시간 : 15초 지속 점령, 적 진입 시 타이머 정지
u  승리조건 : 플레이어(제한시간 내 점령) vs 적(점령을 막고 제한시간 종료) 점령 진행률 50% 이상일 경우 연장전 발동 기능
 
-      4. UI 구성 요소
n  플레이어 HUD : HP Bar, 탄약 수, 궁극기 게이지
n  AI 상태 표시 : 이름, 체력바 간략 표시
n  거점 점령 게이지 : Progress Bar 방식
n  타이머 & 점령률 표시 : 상단 중앙 UI
